# Хочу знать, свободна ли аудитория

А любимое расписание просто так не признаётся.

Собираю информацию только по 10 и 11 корпусам.

## discoverer.py 

Раз в месяц проверяет, изменился ли список учебных групп. Для формирования базы используются все группы высшей школы, 1-2 курсы других ВШ головного вуза и аспирантура по направлению 2.3.1.

## parser.py

Раз в сутки, в 4.00 по МСК, подсматривает, на какие пары и куда отправляются студенты. Куда отправляются - там занято. Куда не отправляются - там свободно.

## Персональные данные

Все фамилии, которые собирает скрипт, замаскированы. Если вы не узнаете маску, то так и надо.
